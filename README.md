
**`TreeAnomaly`: Unsupervised Tree-based Anomaly Detection for SDSS Galaxy Spectra**

This repository provides a suite of unsupervised anomaly detection models leveraging tree-based methods, such as Isolation Forest and LightGBM-based pseudo-labeling, specifically tailored for the analysis of SDSS galaxy spectra. Designed for seamless integration with interpretable machine learning libraries, these models enable comprehensive interpretability of detected anomalies through SHAP and LIME frameworks optimized for spectral data.
